# 🥭 MangoTree - Customer Frontend

A modern, responsive, and beautifully designed customer-facing web application for **MangoTree**, delivering a premium tropical dining experience. Built with React and Vite, this application allows customers to browse the menu, manage their cart, and seamlessly place pre-orders for Takeaway or Dine-in.

## ✨ Features

* **Secure Authentication:** User registration and login system with JWT.
* **Tropical Menu Catalog:** Beautifully categorized menu items with chef-crafted tropical designs and responsive grids.
* **Advanced Cart Management:** Real-time cart updates, quantity adjustments, and dynamic order summary calculations.
* **Streamlined Checkout:** Choose between 'Store Pickup (Takeaway)' or 'Dine-in', select arrival times (12:00 PM - 10:00 PM), and process secure payments.
* **Order History:** Track past orders, view order status updates (Pending, Processing, Completed), and easily reorder favorite dishes.
* **Responsive Design:** 100% mobile-friendly with overlapping UI elements, custom mascots, and modern scroll-locked layouts on desktop.

## 🛠️ Tech Stack

* **Framework:** React.js powered by Vite
* **Styling:** Tailwind CSS (with custom tropical gradients and glassmorphism)
* **Routing:** React Router DOM
* **HTTP Client:** Axios
* **Icons:** Lucide React
